# Cadence DSP Backends

## Supported DSPs (in progress)
- HiFi Audio
- Fusion G3

## Tutorial

Please follow the [tutorial](https://pytorch.org/executorch/main/backends-cadence) for more information on how to run models on Cadence/Xtensa DSPs.
