# W4A16 precision v4

Generated by KernelAgent-Oink(https://github.com/meta-pytorch/KernelAgent).

This immutable Triton generation keeps precision-v3 FP32 affine reconstruction
and final-BF16 MMA operands. It adds previously unavailable M16 stage1 bases and
gives already-supported split8 variants explicit declared IDs, prioritizing the
measured narrow-N M16 risk.
The measured M8 BN32/2-warp/stage2 option is retained.

Matching an emitted/native outer schedule is disclosed and is not itself a
speedup. RTX5090 validation remains external. This module does not implement an
A100 fallback; an eventual top-level architecture selector must route SM80 to
the pinned original native path. That external fallback is legacy baseline
behavior, not canonical-precision improvement.
