# Expanded precision W4A16 v5

Generated by KernelAgent-Oink(https://github.com/meta-pytorch/KernelAgent).

This immutable Triton generation extends the FP32-affine/final-BF16 W4A16
mainloop to logical buckets M1/2/4 using an internal masked M8 tensor-core tile.
It retains focused M8/M16 SM120 controls. There is no Python microbatch loop,
activation quantization, repack, or dense-weight cache.

For M1/2/4, the deployment timing baseline is the actual existing W4A8 complete
invocation, including activation quantization and split reduction. Tuned W4A16
is reported separately. W4A8 output is never used as the precision oracle.
Any A100 fallback is external architecture dispatch to the unchanged original
path; this candidate module does not silently fall back.
